# 복습 퀴즈

수업 끝에 그날 배운 내용을 퀴즈로 풀어 보는 사이트입니다. 교사 컴퓨터 화면을 교실 프로젝터에 띄우고, 학생들은 각자 컴퓨터에서 방 번호로 들어와 답을 고릅니다. 서버나 데이터베이스 없이 GitHub Pages에 올려서 씁니다.

## 화면

| 파일 | 누가 쓰나 | 하는 일 |
|---|---|---|
| `index.html` | 학생 | 방 번호와 이름 입력, 캐릭터 고르기, 문제 풀기 |
| `host.html` | 교사 | 퀴즈 고르기, 대기실(방 번호·QR), 문제 진행, 정답 공개, 순위, 시상대, 결과 저장 |
| `editor.html` | 교사 | 퀴즈 만들기·고치기, CSV로 저장 |

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 무료 계정이면 공개(Public)로 만들어야 Pages를 쓸 수 있습니다.
2. 이 폴더 안의 파일을 모두 저장소에 올립니다. 웹에서 올릴 때는 저장소 첫 화면의 **Add file → Upload files**에 폴더 내용을 끌어다 놓으면 됩니다. `.nojekyll` 파일도 같이 올라가야 합니다.
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 고르고 저장합니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다. 이 주소가 학생 입장 화면이고, 교사는 끝에 `host.html`을 붙여 엽니다.

학생 이름이 들어간 결과 파일은 교사 컴퓨터에만 저장됩니다. 저장소에는 올리지 마세요.

## 수업에서 쓰는 순서

1. 교사: `host.html`을 열고 퀴즈를 고릅니다. 반 이름을 적고 **결과 저장 폴더 지정**을 눌러 두면 정답을 공개할 때마다 그 폴더에 CSV가 저장됩니다(크롬, 엣지, 웨일).
2. **방 만들기**를 누르면 방 번호와 QR코드가 나옵니다.
3. 학생: 사이트 주소로 들어와 방 번호, 이름을 넣고 캐릭터를 고릅니다. QR코드로 들어오면 방 번호는 자동으로 들어갑니다.
4. 교사: 학생이 다 들어오면 **퀴즈 시작**. 모두 답하거나 시간이 끝나면 정답이 공개됩니다.
5. 마지막 문제 뒤에 시상대가 나오고, **문항별 결과 보기**에서 정답률과 학생별 틀린 문항을 보고 CSV로 내려받습니다.

진행 중에 쓸 수 있는 버튼은 문제 화면 아래에 있습니다. `+10초`, `정답 바로 공개`, `이 문제 건너뛰기`(그 문제 점수는 취소), `여기서 끝내기`(지금 문제는 빼고 시상대로).

## 점수

맞히면 `1000 × (1 − (걸린 시간 ÷ 제한 시간) ÷ 2)`점, 틀리거나 시간 안에 못 고르면 0점입니다. 문제가 뜨자마자 맞히면 1000점, 제한 시간 직전에 맞혀도 500점입니다. 걸린 시간은 학생 컴퓨터가 문제를 받은 순간부터 재기 때문에 인터넷이 느린 컴퓨터가 손해 보지 않습니다. 점수가 같으면 응답 시간 합계가 짧은 학생이 앞 순위입니다.

## 퀴즈 CSV 형식

```
번호,문제,선택지1,선택지2,선택지3,선택지4,정답,제한시간,해설,그림
1,광합성이 주로 일어나는 세포 소기관은?,미토콘드리아,엽록체,핵,리보솜,2,20,엽록체 속 엽록소가 빛을 흡수합니다.,
2,식물은 광합성을 할 때 산소를 내보낸다.,O,X,,,1,10,,
```

- 정답은 선택지 번호(1~4)로 적습니다.
- 선택지는 2개부터 4개까지 됩니다. O/X 문제는 선택지1에 O, 선택지2에 X를 적습니다.
- 제한시간은 초 단위이고 비우면 20초입니다.
- 그림 칸에 파일 이름(예: `leaf.png`)을 적고 그 파일을 `quizzes/images/` 폴더에 올리면 문제에 그림이 나옵니다. `https://`로 시작하는 주소를 적어도 됩니다.
- 엑셀에서 그냥 "CSV"로 저장한 파일도, "CSV UTF-8"로 저장한 파일도 모두 읽습니다.

### 저장소에 퀴즈 올려 두기

`quizzes/` 폴더에 CSV를 올리고 `quizzes/index.json`에 한 줄 추가하면 교사 화면의 퀴즈 목록에 나옵니다. 파일 이름은 영문으로 짓는 편이 안전합니다.

```json
{
  "quizzes": [
    { "title": "[예시] 식물의 광합성", "file": "sample-photosynthesis.csv" },
    { "title": "4단원 호흡", "file": "unit4-respiration.csv" }
  ]
}
```

저장소에 올리지 않고 교사 화면에서 **내 컴퓨터의 CSV 불러오기**로 바로 써도 됩니다. 한 번 쓴 퀴즈는 그 컴퓨터의 "최근 사용" 목록에 5개까지 남습니다.

### 편집기

`editor.html`에서 문제를 쓰고 동그라미 번호를 눌러 정답을 표시합니다. 메모장에 적어 둔 문제를 한꺼번에 붙여 넣을 수도 있습니다. 문제 하나는 빈 줄로 나누고, 정답 앞에 `*`를 붙입니다.

```
광합성이 주로 일어나는 세포 소기관은?
미토콘드리아
*엽록체
핵
리보솜
해설: 엽록체 안의 엽록소가 빛을 흡수합니다.
```

**이 퀴즈로 시작**을 누르면 저장하지 않고 바로 교사 화면으로 넘어가고, **CSV로 저장**하면 파일로 받아 저장소에 올리거나 다음에 다시 불러올 수 있습니다. 쓰던 내용은 브라우저에 자동으로 남습니다.

## 결과 파일

| 파일 | 내용 |
|---|---|
| `날짜_반_퀴즈_응답.csv` | 학생이 문제마다 고른 답, 정답 여부, 응답 시간, 점수 (한 줄에 한 학생·한 문제) |
| `날짜_반_퀴즈_순위.csv` | 순위, 이름, 총점, 정답 수, 응답 시간 합계 |
| `날짜_반_퀴즈_문항별.csv` | 문항별 정답률, 선택지마다 고른 학생 수, 무응답 수 |

모두 엑셀에서 한글이 깨지지 않게 BOM이 붙은 UTF-8로 저장됩니다.

## 연결 방식과 주의할 점

교사 브라우저 탭이 방 역할을 하고, 학생 브라우저는 WebRTC로 교사 탭에 직접 연결됩니다(PeerJS 사용). 처음 연결을 이어 줄 때만 PeerJS의 무료 중계 서버(`0.peerjs.com`)를 거치고, 이름이나 답은 그 서버에 남지 않습니다.

- **교사 탭을 닫으면 방이 사라집니다.** 실수로 닫거나 새로고침했으면 `host.html`을 다시 열고 **이어서 진행**을 누르세요. 같은 방 번호로 열리고 학생 화면은 저절로 다시 붙습니다. 결과 저장 폴더는 다시 지정해야 합니다.
- **학생이 새로고침해도** 같은 탭이면 그대로 이어집니다. 탭을 닫았다가 다시 들어와도 같은 이름을 넣으면 원래 점수에 이어 붙습니다. 이미 접속해 있는 이름과 같은 이름이 들어오면 "김민준(2)"처럼 번호가 붙습니다.
- 대기실에서 학생 이름을 누르면 그 학생을 내보낼 수 있습니다. 비속어가 든 이름은 입장할 때 막힙니다.
- **학교망에서 먼저 시험해 보세요.** 학교 방화벽이 `0.peerjs.com`이나 WebRTC 연결을 막으면 학생이 방에 들어오지 못합니다. 그럴 때는 정보 담당 선생님께 해당 주소 허용을 요청해야 합니다.
- 인터넷 없이 같은 컴퓨터에서 화면만 시험해 보려면 주소 끝에 `?mode=local`을 붙입니다. 이 모드에서는 같은 브라우저의 탭끼리만 연결됩니다. 예: `host.html?mode=local`을 연 뒤, 대기실에 나온 주소를 다른 탭 여러 개로 열기.

## 폴더 구성

```
index.html, host.html, editor.html
css/      화면 모양
js/       common.js(공통), host.js, student.js, editor.js
quizzes/  퀴즈 CSV, index.json, images/
vendor/   PeerJS, QR코드 라이브러리, 개구·고운돋움 글꼴(SIL OFL)
```

글꼴과 라이브러리를 모두 폴더 안에 넣어 두어서, 외부 글꼴 사이트가 막힌 학교망에서도 화면이 똑같이 보입니다.
